📋 Important: How Saving Works in Indicolite

Please read and agree before you start building. This protects your work!

  • 💾 Save (to browser): Your project and uploaded assets are stored in this browser, on this computer only. If the browser data is cleared — which public, school, and library computers often do automatically — your work will be permanently lost.
  • ⬇ Save File (recommended): Click Save File to download your whole project as a .indicolite file. Keep it on a USB stick, Google Drive, or email it to yourself. This is the only way to guarantee your work is safe and can be reopened on any computer.
  • 🌐 Hosting: Indicolite does not host or back up your games for you. You are responsible for keeping your own project files and published builds.
  • 🔑 AI features: AI coding help requires your own Anthropic API key, entered in the AI panel. It is stored only in your browser and sent directly to Anthropic — never to us.

⚠️ Indicolite and Phenite Software are not responsible for any lost projects or data. Always use Save File to keep a permanent copy.
